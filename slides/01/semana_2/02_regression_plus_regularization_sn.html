Un modelo lineal para el precio

 

La predicción combina la información disponible:

\[\hat y_i=\hat\beta_0+\sum_{j=1}^{p}\hat\beta_j x_{ij}\]

\(y_i\): precio por noche. \(x_{ij}\): predictor \(j\) del anuncio \(i\).

\(p\) cuenta las columnas después de codificar categorías.

Mínimos cuadrados ordinarios

MCO elige los coeficientes que minimizan

\[RSS=\sum_{i=1}^{n}(y_i-\hat y_i)^2.\]

Información que se solapa

Regularización y complejidad

 

Muchas columnas respecto a \(n\) y predictores correlacionados pueden aumentar la varianza.

Penalizar los coeficientes restringe la flexibilidad del ajuste.

Intercambio sesgo–varianza

Aceptamos sesgo para reducir la sensibilidad a la muestra.

La mejora predictiva se comprueba con datos de validación.

La escala forma parte del modelo

 

\[z_{ij}=\frac{x_{ij}-\bar x_j}{s_j}\]

La misma información, expresada en metros o kilómetros, cambia la magnitud del coeficiente.

Estandarizamos antes de penalizar.

Dentro de cada ajuste

Imputación, codificación y escala se aprenden solo con entrenamiento, también dentro de cada fold.

Ridge: reducir la magnitud

La penalización ridge

 

Ridge combina error de ajuste y magnitud de los coeficientes:

\[\frac{RSS}{2n}+\frac{\lambda}{2}\sum_{j=1}^{p}\beta_j^2\]

\(\lambda\geq0\) controla la penalización.

El intercepto \(\beta_0\) queda fuera.

Contracción L2

Penaliza especialmente coeficientes grandes. En general conserva todas las columnas.

Lasso: contracción y selección

La penalización lasso

 

Lasso penaliza la suma de valores absolutos:

\[\frac{RSS}{2n}+\lambda\sum_{j=1}^{p}|\beta_j|\]

Con suficiente penalización, algunas pendientes quedan exactamente en cero.

Lasso puede seleccionar columnas.

Para pensar

¿Por qué lasso puede llegar a cero?

Código: geometría de ridge y lasso con dos predictores de Airbnb 
# Para leer la geometría aislamos dos predictores reales y estandarizamos X e y.
zg = StandardScaler().fit_transform(train[["number_of_reviews", "number_of_reviews_ltm"]])
yg = (y_train.to_numpy() - y_train.mean()) / y_train.std(ddof=0)
b_ols = LinearRegression(fit_intercept=False).fit(zg, yg).coef_
lam = np.max(np.abs(zg.T @ yg)) / len(yg) * 0.6
b_ridge = Ridge(alpha=len(yg)*lam, fit_intercept=False).fit(zg, yg).coef_
b_lasso = Lasso(alpha=lam, fit_intercept=False, max_iter=50000, tol=1e-8).fit(zg, yg).coef_
lim = max(np.abs(b_ols).max()*1.8, 0.2)
a, b = np.meshgrid(np.linspace(-lim, lim, 220), np.linspace(-lim, lim, 220))
# Forma cuadrática exacta de RSS/(2n), sin crear una matriz (n x puntos).
G, h = zg.T @ zg / len(yg), zg.T @ yg / len(yg)
loss = .5*(G[0,0]*a*a + 2*G[0,1]*a*b + G[1,1]*b*b) - h[0]*a - h[1]*b + .5*np.mean(yg**2)
fig, axes = plt.subplots(1, 2, figsize=(16, 6.5))
for ax, name, beta, color in zip(axes, ["Ridge: círculo", "Lasso: rombo"],
                                [b_ridge, b_lasso], [tv.BLUE, tv.TERRACOTTA]):
    target = .5*np.mean((yg-zg@beta)**2)
    minimum = .5*np.mean((yg-zg@b_ols)**2)
    levels = np.unique(np.r_[np.linspace(minimum+1e-5, loss.max(), 12), target])
    ax.contour(a, b, loss, levels=levels, colors=tv.GRAY, alpha=.55)
    if name.startswith("Ridge"):
        angle = np.linspace(0, 2*np.pi, 240)
        radius = np.linalg.norm(beta)
        ax.fill(radius*np.cos(angle), radius*np.sin(angle), color=color, alpha=.2)
    else:
        radius = np.abs(beta).sum()
        ax.fill([radius,0,-radius,0], [0,radius,0,-radius], color=color, alpha=.2)
    ax.scatter(*b_ols, marker="x", color=tv.NAVY, s=95, label="MCO")
    ax.scatter(*beta, color=color, s=70, label="Penalizado")
    ax.axhline(0, color=tv.GRAY, lw=.6); ax.axvline(0, color=tv.GRAY, lw=.6)
    ax.set(title=name, xlabel="Coeficiente: reseñas totales", ylabel="Coeficiente: reseñas en 12 meses",
           xlim=(-lim,lim), ylim=(-lim,lim), aspect="equal")
    ax.legend(loc="upper left")
fig.tight_layout()
plt.show()

El menor error admisible toca la restricción. Las esquinas del rombo favorecen soluciones sobre los ejes.

Elastic net: combinar L1 y L2

La penalización elastic net

 

La mezcla combina selección y contracción:

\[\frac{RSS}{2n}+\lambda\left[\rho\sum_{j=1}^{p}|\beta_j|+ \frac{1-\rho}{2}\sum_{j=1}^{p}\beta_j^2\right]\]

\(\lambda\geq0\): intensidad total.

\(0\leq\rho\leq1\): proporción L1.

\(\rho=1\): lasso. \(\rho=0\): ridge.

Dos hiperparámetros

Con \(0<\rho<1\), puede eliminar columnas y mantener juntas señales correlacionadas.

Elegimos intensidad y mezcla por validación.

Tres penalizaciones, una comparación

 

Modelo Penalización ¿Ceros exactos? Hiperparámetros
Ridge Cuadrados (L2) No los induce Intensidad
Lasso Valores absolutos (L1) Puede producirlos Intensidad
Elastic net Mezcla L1 y L2 Puede producirlos Intensidad y mezcla

Ninguna familia gana por definición. Comparten datos, preprocesado y criterio de evaluación.

Elegir y evaluar

Ajuste, selección y test

 

  1. Ajuste: estimar \(\beta\) con los datos de entrenamiento.
  2. Selección: comparar penalizaciones y familias mediante CV.
  3. Test: evaluar la decisión ya fijada.

Para pensar

Si elegimos \(\lambda\) mirando el test, ¿sigue siendo una evaluación independiente?

Validación cruzada en cinco partes

Azul: ajustar. Terracota: validar. Repetimos para cada candidato y promediamos su RMSE.

La fórmula y los nombres en Python

 

En las fórmulas anteriores, la pérdida es \(RSS/(2n)\).

Estimador Intensidad en la API Mezcla
Ridge alpha \(=n\lambda\) L2
Lasso alpha \(=\lambda\) L1
ElasticNet alpha \(=\lambda\) l1_ratio \(=\rho\)

Un mismo valor de alpha no supone la misma penalización en ridge y lasso.

El mismo pipeline para las tres familias

 

Código: preprocesado y búsqueda de elastic net 
modelo = Pipeline([

Ridge busca su alpha. Lasso busca el suyo. Elastic net busca intensidad y mezcla.
